# 洞穴沉积层样本链

沉积层封存、年代采样的封条—冷链—交接管理，替代微信群口头交接。同时保留原「洞穴微环境巡测」的样点档案与巡测记录。

## 启动

```bash
npm install
npm start          # http://localhost:3912
npm test           # 判定层规则测试（node:test）
```

数据保存在 `data/db.json`。

## 样本链规则

1. **登记**：钻孔、层位、深度、封存时间、封条号、登记人一次登齐，重量可后补。
2. **同层位唯一在途**：同钻孔 + 同层位只允许一条未闭环样单（已登记 / 在途 / 待处理 / 待重核均占位；已接收为闭环）。重复建样不新建，直接返回已有样单。
3. **发运核对**：运输温度 **> 8℃**、**封条破损**、**重量缺失** 任一命中即转「待处理」，**不进送检清单**；整改后可重新核对发运。
4. **实验室接收（双人）**：接收核对人不得是登记人或运输人；逐项核对封条号与重量，系统按核对结果自动记「合格 / 不合格」。不合格转待处理，合格进入已接收归档。
5. **更正重排**：已接收样本的**深度或封存时间**更正后，原结论立即失效、样单回到送检清单「待重核」，需另一人重新核对；旧结论带失效原因归档，卡片内「旧档」永久可查。

## 两个可见队列

- **送检清单**：在途 + 待重核，等待实验室另一人核对。
- **待处理**：冷链 / 封条 / 重量异常或实验室判不合格，整改后可重发。
- 另有「待发运（已登记）」「已接收 / 已归档」两个队列。

## 分层结构

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 存储 | `lib/store.js` | 只读写 `data/db.json`，无业务规则 |
| 判定 | `lib/sample-chain.js` | 样本链全部状态机与规则（纯函数，可单测） |
| 装配 | `server.js` | HTTP 路由，样本专用接口见下；通用 CRUD 对 `samples` 关闭 |
| 页面 | `public/app.js` / `index.html` / `styles.css` | 「样本链」标签页，四队列看板 |

### 样本专用接口

- `POST /api/sample/register` — 登记；重复时返回 200 + 原样单（`duplicated: true`）
- `POST /api/sample/:id/dispatch` — 发运核对（温度 / 封条 / 重量 / 运输人）
- `POST /api/sample/:id/receive` — 实验室另一人核对（封条号 / 重量 / 接收人）
- `POST /api/sample/:id/correct` — 深度 / 封存时间更正，结论失效重排
- `GET /api/sample/board` — 四个队列取数

样本不能通过通用 `POST/PATCH/DELETE /api/samples...` 修改，原档不可删除。
