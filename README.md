# 沉积层样本链系统

洞穴修复队封存沉积层做年代采样的样本链（chain of custody）：封条、冷链、双人核对全程留痕，替代微信群口头交接。

## 启动

```bash
npm install
npm start        # http://localhost:3912
npm test         # 23 项端到端规则测试
```

数据保存在 `data/db.json`（可用环境变量 `CHAIN_DB_FILE` 指定其他文件）。

## 分层结构

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 判定 | `lib/rules.js` | 纯函数规则：同层位唯一在途、超温/封条/重量判异、双人核对、结论失效。服务端与页面共用同一份 |
| 存储 | `lib/storage.js` | JSON 文件读写 + 串行写互斥，不含任何业务判定 |
| 接口 | `server.js` | 解析请求、调判定层、经存储层落盘 |
| 页面 | `public/` | 三个页面：队列看板、登记钻孔、接收与旧档 |

## 业务规则

- **登记**：钻孔、层位、深度、封存时间、封条号、重量、登记人。同钻孔同层位只准一条在途（在途/送检/待处理均占位），重复建样不新建，直接返回已有样单。
- **运输核验**：运输最高温 **超过 8℃**（8.0℃ 放行）、封条破损、登记重量缺失，任一命中即转「待处理」，不进送检清单；待处理样本处置复检、缺陷全部解除后才能重回送检清单。
- **实验室接收**：必须由**另一人**（不得是登记人或运输核验人）逐项核对封条号与复称重量（容差 ±0.5g）并记录合格/不合格结论；核对不符不能判合格，判不合格退回待处理，本次结论仍留档。
- **更正**：深度或封存时间更正须填操作人与原因；已接收样本被更正后，原接收结论立即作废（标记 `void`，旧档可查），样本重排回送检清单，须重新双人核对接收。

## 页面

- `/` 队列看板：**在途/送检清单** 与 **待处理** 两个队列同屏可见，可在卡片上直接完成核验、接收、复检、更正。
- `/register.html` 登记钻孔与封样。
- `/archive.html` 已接收样本 + 接收结论旧档（可筛选已作废记录）。
